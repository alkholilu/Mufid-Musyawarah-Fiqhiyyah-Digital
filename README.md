# Mufid - Musyawarah Fiqhiyyah Digital

Platform tata kelola, dokumentasi, kolaborasi real-time, dan publikasi hasil sidang keputusan hukum Islam (Bahtsul Masail).

## 🚀 Tech Stack
- **Frontend**: Next.js 14, React 18, Tailwind CSS, Lucide React
- **Backend & Database**: Supabase (PostgreSQL, Realtime, Auth, Storage)
- **Language**: JavaScript / TypeScript

## 🛠️ Installation & Setup
```bash
# Install dependencies
npm install

# Run local development server
npm run dev
```
